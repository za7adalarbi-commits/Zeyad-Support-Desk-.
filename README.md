# Zeyad Support Desk — دليل مبسّط

موقع شخصي لتسجيل مكالمات العملاء والشكاوى ومواعيد المتابعة، مع إمكانية حفظ تقرير المشكلة PDF.

## تشغيل الموقع محليًا

1. فك ضغط الملف.
2. افتح `index.html` بالمتصفح لمعاينة الواجهة.
3. الحفظ الفعلي والتذكيرات يحتاجان إعداد Google Sheets وGoogle Apps Script كما في هذا الدليل.

## ملفات المشروع: أعدّل إيه؟

| الملف | استخدامه |
|---|---|
| `index.html` | ترتيب عناصر الصفحة والحقول الموجودة في النموذج |
| `styles.css` | الألوان، الأحجام، المسافات، وشكل الموقع |
| `app.js` | وظائف الموقع والنصوص العربية والإنجليزية |
| `apps-script/Code.gs` | الربط مع Google Sheets وإرسال تذكيرات Gmail |
| `EASY-EDIT-AR.md` | شرح سريع للتعديلات الشائعة بالعربي |

## نشر الواجهة مجانًا على GitHub Pages

1. أنشئ مستودعًا باسم `zeyad-support-desk` على GitHub.
2. ارفع الملفات التالية إلى جذر المستودع: `index.html`, `styles.css`, `app.js`, `.nojekyll`.
3. افتح **Settings → Pages**.
4. اختر **Deploy from a branch**، ثم `main` والمجلد `/(root)`، واضغط **Save**.
5. انتظر رابط الموقع الذي يعرضه GitHub Pages.

## ربط Google Sheets والتذكيرات

1. أنشئ Google Sheet جديدًا وانسخ معرّف الملف من الرابط؛ هو النص بين `/d/` و`/edit`.
2. افتح [Google Apps Script](https://script.google.com/) وأنشئ مشروعًا جديدًا.
3. انسخ محتوى `apps-script/Code.gs` إلى محرر Apps Script.
4. من **Project Settings → Script properties** أضف:
   - `SHEET_ID`: معرّف Google Sheet.
   - `ACCESS_TOKEN`: رمز طويل وعشوائي لا تشاركه.
5. شغّل الدالة `setup` ووافق على الصلاحيات المطلوبة.
6. اختر **Deploy → New deployment → Web app**، واجعل التنفيذ **Me**، والوصول **Anyone** إذا كان هذا مناسبًا لسياسة شركتك.
7. انسخ رابط التطبيق الذي ينتهي بـ `/exec`.
8. افتح الموقع، واضغط **الإعدادات**، وأدخل الرابط والرمز، ثم احفظ.
9. اختبر باستخدام بيانات وهمية أولًا. جرّب حفظ سجل وتذكيرًا إلى بريدك.

## الاستخدام اليومي

- اضغط **إضافة سجل** لتسجيل مكالمة أو شكوى.
- اكتب اسم العميل والعنوان والتفاصيل؛ هذه الحقول مطلوبة.
- حدّد حالة المشكلة وموعد التذكير وبريدك الإلكتروني إذا احتجت تذكيرًا.
- أضف كل متابعة جديدة في خانة **ملاحظة / تحديث جديد** حتى تظهر في سجل التحديثات.
- افتح السجل واضغط **تصدير PDF**، ثم اختر **Save as PDF** في نافذة الطباعة.

## تنبيهات مهمة

- لا ترفع بيانات العملاء أو رموز الوصول أو نسخة Google Sheet إلى GitHub.
- لا تستخدم أرقام الهوية أو بيانات عملاء حقيقية قبل موافقة شركتك على التخزين والصلاحيات.
- هذا إصدار شخصي أولي؛ رمز الوصول ليس بديلًا عن نظام مصادقة احترافي. رابط Apps Script العام قد يكون متاحًا عبر الإنترنت، كما أن طلبات القراءة تستخدم الرمز في الرابط. لا تستخدمه للبيانات الحساسة.
- التذكير يفحص المواعيد تقريبًا كل 15 دقيقة، وقد يصل البريد بعد الموعد بقليل. تخضع الخدمة لحدود Google.
- إذا عدّلت `Code.gs` بعد النشر، افتح **Deploy → Manage deployments → Edit** واختر إصدارًا جديدًا ثم انشره.
